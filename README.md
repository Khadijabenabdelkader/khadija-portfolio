# Khadija Ben Abdelkader — Portfolio

Responsive React + Vite portfolio with a soft nude, beige, ivory, and black visual style.

## Run locally

```bash
npm install
npm run dev
```

## CV files and portrait

- English CV: `public/cv/Resume_KhadijaBenAbdelkader.pdf`
- French CV: `public/cv/CV_KhadijaBenAbdelkader.pdf`
- Portrait: `public/images/khadija.jpg`

## Add the four project demo videos

Open `src/App.jsx`. In the `projects` array, replace each empty `videoUrl: ''` with the direct URL for that project's video. A demo button will appear automatically when a URL is supplied.

The repository links currently point to your GitHub profile because individual repository URLs were not supplied. Replace each project's `repoUrl` with its specific repository link when available.

## Build for production

```bash
npm run build
```

## Project demo videos

The project cards are configured to open these local files:

- `public/videos/bricklogistics.mp4`
- `public/videos/sac-consulting.mp4`
- `public/videos/satp-website.mp4`
- `public/videos/resin-ecommerce.mp4`

Put your existing demo videos at these paths (or edit the matching `videoUrl` values in `src/App.jsx` to match the names already in your `public` directory). The source archive supplied for this update did not contain video files, so they are not embedded in this ZIP.
